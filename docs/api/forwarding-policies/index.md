# Forwarding Policy Management

This section covers the API endpoints for managing email forwarding policies.

## Overview

Forwarding policy endpoints allow you to control how emails are forwarded within and outside your organization. You can set up automatic forwarding rules, manage forwarding restrictions, and monitor forwarding behavior.

## Available Operations

- Create forwarding policies
- List existing forwarding policies
- Update forwarding rules
- Delete forwarding policies
- Configure forwarding restrictions and destinations

## Authentication

All forwarding policy management endpoints require authentication. Please refer to the [Authentication](/docs/authentication) section for details on how to authenticate your requests.

## Permissions

Appropriate permissions are required to perform forwarding policy management operations. See the [Permissions](/docs/permissions) section for more information.
