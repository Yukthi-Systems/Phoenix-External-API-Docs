# Mailbox Management

This section covers the API endpoints for managing mailboxes in your domain.

## Overview

Mailbox management endpoints allow you to create, read, update, and delete mailboxes for your domains. You can manage mailbox settings, quotas, and other configurations through these endpoints.

## Available Operations

- Create new mailboxes
- List existing mailboxes
- Update mailbox settings
- Delete mailboxes
- Manage mailbox quotas and permissions

## Authentication

All mailbox management endpoints require authentication. Please refer to the [Authentication](/docs/authentication) section for details on how to authenticate your requests.

## Permissions

Appropriate permissions are required to perform mailbox management operations. See the [Permissions](/docs/permissions) section for more information.
