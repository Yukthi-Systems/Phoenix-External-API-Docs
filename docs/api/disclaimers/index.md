# Disclaimer Management

This section covers the API endpoints for managing email disclaimers.

## Overview

Disclaimer management endpoints allow you to create and manage disclaimers that are automatically appended to outgoing emails. This is useful for legal compliance, branding, and corporate communications.

## Available Operations

- Create email disclaimers
- List existing disclaimers
- Update disclaimer content and settings
- Delete disclaimers
- Configure disclaimer application rules

## Authentication

All disclaimer management endpoints require authentication. Please refer to the [Authentication](/docs/authentication) section for details on how to authenticate your requests.

## Permissions

Appropriate permissions are required to perform disclaimer management operations. See the [Permissions](/docs/permissions) section for more information.
