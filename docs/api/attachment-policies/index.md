# Attachment Policy Management

This section covers the API endpoints for managing email attachment policies.

## Overview

Attachment policy endpoints allow you to control how email attachments are handled. You can block certain file types, set size limits, and enforce security measures for attachments.

## Available Operations

- Create attachment policies
- List existing attachment policies
- Update policy rules and restrictions
- Delete attachment policies
- Configure allowed/blocked file types and size limits

## Authentication

All attachment policy management endpoints require authentication. Please refer to the [Authentication](/docs/authentication) section for details on how to authenticate your requests.

## Permissions

Appropriate permissions are required to perform attachment policy management operations. See the [Permissions](/docs/permissions) section for more information.
