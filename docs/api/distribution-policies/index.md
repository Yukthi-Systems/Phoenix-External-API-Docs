# Distribution Policy Management

This section covers the API endpoints for managing email distribution policies.

## Overview

Distribution policy endpoints allow you to manage distribution lists and mailing groups. You can control how emails are distributed to multiple recipients, manage distribution list membership, and configure distribution rules.

## Available Operations

- Create distribution policies
- List existing distribution policies
- Update distribution rules
- Delete distribution policies
- Manage distribution list members and settings

## Authentication

All distribution policy management endpoints require authentication. Please refer to the [Authentication](/docs/authentication) section for details on how to authenticate your requests.

## Permissions

Appropriate permissions are required to perform distribution policy management operations. See the [Permissions](/docs/permissions) section for more information.
